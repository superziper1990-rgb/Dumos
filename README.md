# Dumos
Dumos is an Android software that acts as a BIOS simulator (note: Dumos is in the prototyping phase, so finding bugs means fewer bugs later). To use Dumos: 1. Install PyDroid 3 from the Play Store. And the code, 2: open pydroid and in the app's + button go to the "open" tab, then find your code in its internal storage, then choose your code. Done
